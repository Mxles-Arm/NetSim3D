# NetSim3D

โครงงานเกมจำลองการปฏิบัติงานด้านเครือข่ายสามมิติ พัฒนาด้วย Godot และ Blender

## โครงสร้างโครงการ

- `net-sim-3d/` — โปรเจกต์เกม Godot
- `3Dmodel/blend/` — ไฟล์ต้นฉบับโมเดล Blender
- `3Dmodel/exports/` — โมเดลที่ส่งออกสำหรับนำไปใช้งาน
- `3Dmodel/scripts/` — สคริปต์สร้างและตรวจสอบโมเดล
- `3Dmodel/renders/` — ภาพพรีวิวโมเดลและฉาก

เปิดโปรเจกต์เกมจาก `net-sim-3d/project.godot`
